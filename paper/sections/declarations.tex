\section*{Data and code availability}

The manuscript source, MOOSE implementation, input decks, curated numerical
data, verification drivers, and figure scripts are publicly available at
\url{https://github.com/johntfoster/finite-strain-biot-poromechanics}.
The repository's submission release identifies the source revision and
provides checksummed archives of the manuscript, data, and supplemental
website. The configured development container supplies the numerical
environment used for ordinary verification. The extended refinement and
stability studies are reproduced by the separate commands documented in the
repository.

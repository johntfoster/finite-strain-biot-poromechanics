# Citation Verification Checklist

- Identify the exact manuscript claim and source location.
- Locate every key in `all.bib`; check title, authors, year, venue, pages, and DOI
  against an authoritative metadata source.
- Inspect the source PDF or official full text. For equations, inspect the
  equation, definitions, and assumptions; for empirical claims, inspect the
  figure/table and data provenance.
- Record one verdict: `supports`, `partially-supports`, `related-only`,
  `contradicts`, or `not-verifiable`.
- For released data, distinguish measured quantities from quantities calculated
  algebraically in the workbook.
- Preserve manuscript text when evidence is unavailable and report the gap.

Report claim, citation key, metadata result, exact source evidence, verdict,
and required action.

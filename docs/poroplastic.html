2 · Poroplastic Biot coefficient

A suite of single-element demonstrations for the plastic pore-allocation correction to the Biot coefficient. When plastic (inelastic) flow changes the solid volume fraction, the fixed-pressure Biot coefficient becomes B = 1 − (1 − Bel)/ap, where Bel is the elastic coefficient at total J and ap is the plastic pore allocation. The canonical engine is the stateful multiplicative ideal Drucker–Prager return mapping (F = Fᵉ Fᵖ, radial return on the Kirchhoff stress).

The general fixed-history, fixed-pressure tangent of the active plastic local system is also computed by pure AD (no finite differences) via ADPlasticStateBiotMaterial + ADConstrainedSkeletonBiotMaterial, and verified equal to the reduced closed form to machine precision.

MOOSE implementation files

  • ADTensorialPoroplasticBiotMaterial Stateful multiplicative ideal Drucker–Prager return mapping. Forms the elastic trial Fᵉtr = F (Fᵖn)⁻¹, reconstructs the single-prime Kirchhoff stress, and performs the radial return with exact symmetric matrix exponential; stores Fᵖ and aᵖ = det Fᵖ. Why: the canonical inelastic update that produces the plastic pore allocation used by the coefficient correction; inactive/elastic steps freeze the plastic state (immediate elastic unloading, reload re-yields).
  • ADPlasticStateBiotMaterial Local-state residual provider for the fixed-history, fixed-pressure tangent of the active poroplastic branch: route-A mapping φs = φs0 r/(ratio·aᵖ) with aᵖ frozen (non-AD), publishing the two local residuals and their partials for the dense AD solve. Why: supplies the residuals consumed by the general tangent so the general path can be verified against the reduced closed form.
  • ADPoroplasticBiotCoefficientMaterial Plastic pore-allocation correction B = 1 − (1 − Bel)/aᵖ read from the elastic oracle and the stored allocation. Why: the reduced route-A closure that the general AD path and the stateful engine are checked against.
  • ADDruckerPragerPoroplasticBiotMaterial Earlier scalar Drucker–Prager return mapping on the single-prime Kirchhoff stress with the surface f = q′ − M p′, including the optional biot_feedback fixed-point iteration. Why: the predecessor scalar prototype retained for the drained compression and feedback comparisons.
  • ADConstantDeformationGradientMaterial Prescribes a uniform diagonal deformation gradient F = diag(λt, λa, λo) (optionally time-ramped). Why: drives the single-element material tests without a displacement solve.

Python scripts that produce the results and figures

  • curate_poroplastic_delta_b.py Runs the monotonic compression sweep and curates validation/poroplastic_delta_b.csv.
  • check_poroplastic_general_path.py Runs the general-path deck and verifies B_reduced = B_general to machine precision; curates poroplastic_general_path.csv.
  • check_poroplastic_load_unload.py Runs the unload-branch deck and curates poroplastic_load_unload.csv.
  • check_poroplastic_b_feedback.py Runs the feedback deck over pressure and compression scans; curates poroplastic_b_feedback.csv.
  • check_tensorial_load_unload.py Runs the load–unload–reload deck and verifies the elastic-unload / re-yield gates; curates tensorial_load_unload.csv.
  • plot_poroplastic_delta_b.py Plots ΔB vs. compression.
  • plot_poroplastic_b_feedback.py Plots the implicit-coefficient feedback (corrected vs. elastic coefficient and the plastic-increment over-prediction).
  • plot_poroplastic_load_unload.py Plots the load–unload branch coefficients.
  • plot_tensorial_load_unload.py Plots the stateful tensorial load–unload–reload loop (aᵖ and B).
  • sweep_poroplastic_b_feedback.py Standalone sweep driver for the feedback deck (companion to the check script).

MOOSE implementation catalog

Every object in the minimal MOOSE application (moose_app/), linked to its source file with a short description of what it implements and why it exists. Header (.h) and implementation (.C) links point into the repository.

Materials

  • ADSolidReferenceKinematics Deformation gradient F, Jacobian J, J̇, F⁻¹, and J F⁻ᵀ from the displacement gradients. Why: the solid-reference kinematics consumed by every pull-back and the Biot transform.
  • ADLocalElasticMineralBiotMaterial Elastic mineral state: intrinsic solid density, solid volume fraction, constraint residuals and partial derivatives, plus a closed-form Biot oracle. Why: the elastic verification specialization and independent oracle.
  • ADConstrainedSkeletonBiotMaterial Solves the AD-valued implicit local tangent at fixed pressure and fixed referential solid mass; returns the production Biot coefficient. Why: the production fixed-pressure Biot tangent.
  • ADVolumetricBarotropicSkeletonStressMaterial Pressure-coupled effective skeleton stress from the volumetric barotropic potential. Why: supplies the double-prime stress P″.
  • ADReferenceSolidStressMaterial Applies the inverse Biot transform to P″ and assembles the total first Piola stress. Why: forms the total mixture stress for momentum.
  • ADBinarySolidSpatialMassMaterial Source-free solid partial-density balance pulled to the reference; normalized referential solid mass and its AD rate. Why: closes the spatial solid mass balance.
  • ADBiotPressureStorageMaterial Exact single-water mass storage J(1−φs)ρ̄f(p) and its AD time rate. Why: the water accumulation without a prescribed storage modulus.
  • ADBiotDarcyReferenceFluxMaterial Pulls the Q1 pressure-gradient Darcy mass flux to the reference configuration. Why: the reference Darcy flux for the water balance.
  • ADTensorialPoroplasticBiotMaterial Stateful multiplicative ideal Drucker–Prager return mapping (F = Fᵉ Fᵖ) with exact symmetric matrix exponential; stores Fᵖ and aᵖ. Why: the canonical inelastic update for the poroplastic demonstrations.
  • ADPlasticStateBiotMaterial Route-A local residual provider for the fixed-history, fixed-pressure plastic tangent with aᵖ frozen. Why: feeds the general AD tangent for the poroplastic oracle checks.
  • ADPoroplasticBiotCoefficientMaterial Plastic pore-allocation correction B = 1 − (1 − Bel)/aᵖ. Why: the reduced route-A closure used as a reference.
  • ADDruckerPragerPoroplasticBiotMaterial Scalar Drucker–Prager poroplastic return mapping on the single-prime Kirchhoff stress, with optional biot_feedback fixed-point iteration. Why: the scalar prototype for the feedback comparisons.
  • ADConstantDeformationGradientMaterial Prescribes a uniform diagonal F (optionally time-ramped). Why: drives single-element material tests without a displacement solve.

Kernels

  • ADReferenceMaterialStorageRateTerm Atomic conservative storage rate supplied as an AD reference-rate property (time kernel). Why: assembles the time derivatives of the solid and water accumulations.
  • ADReferenceComponentFluxTerm Atomic weak-divergence term for one named reference component flux. Why: assembles the Darcy transport term.
  • ADMaterialPropertyResidual Weak algebraic residual using an AD material property. Why: assembles the local constraint residuals into the Newton system.
  • ADReferenceSolidMomentum Quasi-static solid-skeleton momentum component on the reference configuration. Why: the momentum residual for displacement.

Postprocessors & application

  • ADMaterialScalarL2Error Element-integral L2 error of a material property against an analytical function. Why: reports the Biot-identity, mineral-EOS, and referential-mass diagnostics.
  • NonlinearBiotADApp Application object registering all materials, kernels, and postprocessors. Why: the minimal MOOSE application entry point.
  • main.C Standard MOOSE main entry point. Why: the executable.

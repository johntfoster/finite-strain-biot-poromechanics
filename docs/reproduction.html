Reproducing the manuscript results

Everything needed to rebuild the application, run the verification, regenerate the figures, and rebuild the manuscript from a clean clone. The one-shot entry point is scripts/reproduce_all.sh, which runs the complete pipeline end to end.

Requirements are pinned by the reproduction setup script (MOOSE commit abafb58b67a6037c6723ffeb19647c84484466da and the tested conda package versions).

One-shot script

./scripts/reproduce_all.sh

The script performs the steps below in order and stops on the first failure.

Step-by-step commands

0 · Inspect or provision the environment

git submodule update --init --recursive
make setup

Launch a configured Codespace. Setup installs MOOSE, builds the application and manuscript, and prepares the website. The editor opens during setup. Follow tail -f .agent-runtime/codespace-setup.log and wait for the Ready message before running commands. Use make serve and forwarded port 8000 to preview the site.

Every example input and its implementation links.

1 · Shared-source integrity check

tools/sync_biot_moose.py check

2 · Build the MOOSE application

make build

3 · Verify the constitutive derivation and run standard tests

make derivation
make test

4 · Mandel analytical + AD verification

make mandel

The closed-form Biot coefficient is checked against the general implicit tangent and centered differences of perturbed mineral solves. The coupled outer AD Jacobian, mass and EOS residuals, and analytical profiles are checked separately.

5 · Verify and regenerate implicit poroplastic data

make plastic

The material checks physical mass, mineral compression, energy-derived stress, flow, yield, objectivity and derivatives.

6 · Regenerate coupled plastic and stability studies

make plastic-flow
make stability

These full studies include coupled storage, elastic recovery, mesh and time refinement, and the six-case stability matrix. They can take hours. Set POROPLASTIC_MPI_RANKS no higher than the allocated CPU count to use MPI. The standard test suite skips these two heavy drivers.

7 · Regenerate supplementary examples

make examples

Loading and frozen-history examples use the same constitutive law. The feedback sweep records an independently identified inadmissible apex state separately from its smooth-cone solutions.

8 · Regenerate all figures

make figures

This target renders the curated numerical data. Running it alone redraws the figures without rerunning their simulations; the preceding steps regenerate the numerical evidence.

9 · Build the manuscript

make paper

10 · Provenance hashes and repository validation

make provenance
make validate

The provenance record separates required package versions from the environments observed by simulation drivers. New runs record package versions, the framework revision, executable hash, and output hashes. Reusing a completed run preserves its original observations. Historical results without those records are explicitly marked as not recorded; regenerating file hashes does not supply missing execution history.

Constitutive verification

Independent checks reconstruct the mineral state, recover both effective stresses from the energy, and verify plastic flow, distention, hardening, yield consistency, and dissipation. The checks include unequal principal stretches at nonzero pore pressure, the perfectly plastic limit, and load-increment refinement on the smooth yield surface.

Run make plastic for the material-point checks. The verification documentation describes the procedures and links to the driver and recorded results.

Verification of the discrete residuals

Independent finite differences check the constitutive fluid-storage terms and the assembled AD Jacobians in elastic, active-plastic, and coupled poroplastic calculations. Integrated fluid exchange is compared with water-mass change, and time-step refinement measures the mass drift from the chain-rule time discretization.

The verification documentation gives the test procedures, tolerances, and treatment of elastic–plastic switching. Run make test for the ordinary regressions and make plastic-flow for the full coupled study.

Coupled plastic compression test

Run the coupled storage and Jacobian checks, the mesh and time-step study, and the elastic-limit comparison before curating the contour and history data.

POROPLASTIC_MPI_RANKS=8 make plastic-flow
make figures
make paper
make provenance
make validate

The MPI rank count is optional; the verification record lists the ranks used. The plotted calculation uses a 40 × 4 mesh, a uniform 0.0025 s step, and isotropic hardening modulus 100 MPa. The constitutive material defaults to zero hardening; the compression deck and material-point publication driver select initial cohesion 20 MPa and hardening modulus 100 MPa. The default material-point regression retains the perfectly plastic limit. Results and numerical limits. The spatial-stability audit gives the separate zero-hardening controls and hardening refinement commands.

Reproducing the manuscript results

Everything needed to rebuild the application, run the verification, regenerate the figures, and rebuild the manuscript from a clean clone. The one-shot entry point is scripts/reproduce_all.sh, which runs the complete pipeline end to end.

Requirements are pinned by the MOOSE conda setup skill (MOOSE commit abafb58b67a6037c6723ffeb19647c84484466da and the tested conda package versions).

One-shot script

./scripts/reproduce_all.sh

The script performs the steps below in order and stops on the first failure.

Step-by-step commands

0 · Inspect or provision the environment

agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh status
agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh setup   # only when provisioning is needed

1 · Shared-source integrity check

tools/sync_biot_moose.py check

2 · Build the MOOSE application

make build

3 · Run all MOOSE tests (Mandel + poroplastic)

make test
cd moose_app
../agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 ../.agent-runtime/moose/python/run_tests --no-color -j1 --re=poroplastic
cd ..

4 · Regenerate the poroplastic validation data

agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 validation/scripts/curate_poroplastic_delta_b.py
agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 validation/scripts/check_poroplastic_general_path.py
agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 validation/scripts/check_poroplastic_load_unload.py
agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 validation/scripts/check_poroplastic_b_feedback.py
agent_environment/skills/setup-moose-conda/scripts/moose_conda_env.sh run -- \
  python3 validation/scripts/check_tensorial_load_unload.py

5 · Mandel analytical + AD verification

make mandel

6 · Regenerate all figures

make figures

7 · Build the manuscript

make paper

8 · Provenance hashes and repository validation

make provenance
make validate

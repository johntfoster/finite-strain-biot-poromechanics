Reproducing the manuscript results

Everything needed to rebuild the application, run the verification, regenerate the figures, and rebuild the manuscript from a clean clone. The one-shot entry point is scripts/reproduce_all.sh, which runs the complete pipeline end to end.

Requirements are pinned by the reproduction setup script (MOOSE commit abafb58b67a6037c6723ffeb19647c84484466da and the tested conda package versions).

One-shot script

./scripts/reproduce_all.sh

The script performs the steps below in order and stops on the first failure.

Step-by-step commands

0 · Inspect or provision the environment

git submodule update --init --recursive
make setup

Launch a configured Codespace. Setup installs MOOSE, builds the application and manuscript, and prepares the website. Wait for setup to finish before running commands. Use make serve and forwarded port 8000 to preview the site.

Every example input and its implementation links.

1 · Shared-source integrity check

tools/sync_biot_moose.py check

2 · Build the MOOSE application

make build

3 · Run all MOOSE tests

make test

4 · Verify and regenerate implicit poroplastic data

make plastic
make examples

The current material checks physical mass, mineral compression, energy-derived stress, flow, yield, objectivity and derivatives. Supplementary loading and frozen-history examples use the same constitutive law. The feedback sweep records an independently identified inadmissible apex state separately from its smooth-cone solutions.

5 · Mandel analytical + AD verification

make mandel

The closed-form Biot coefficient is checked against the general implicit tangent and centered differences of perturbed mineral solves. The coupled outer AD Jacobian, mass and EOS residuals, and analytical profiles are checked separately.

6 · Regenerate all figures

make figures

7 · Build the manuscript

make paper

8 · Provenance hashes and repository validation

make provenance
make validate

Coupled plastic compression test

Run the coupled storage and Jacobian checks, the mesh and time-step study, and the elastic-limit comparison before curating the contour and history data.

POROPLASTIC_MPI_RANKS=8 make plastic-flow
make figures
make paper
make provenance
make validate

The MPI rank count is optional; the verification record lists the ranks used. The plotted calculation uses a 40 × 4 mesh, a uniform 0.0025 s step, and isotropic hardening modulus 100 MPa. The constitutive material defaults to zero hardening; the compression deck and material-point publication driver select initial cohesion 20 MPa and hardening modulus 100 MPa. The default material-point regression retains the perfectly plastic limit. Results and numerical limits. The spatial-stability audit gives the separate zero-hardening controls and hardening refinement commands.
